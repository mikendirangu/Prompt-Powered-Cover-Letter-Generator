# ⚡ Prompt-Powered Cover Letter Generator using Gemini API

## 1. Title & Objective

**Title:**  
Prompt-Powered Cover Letter Generator using Gemini API

**Objective:**  
The goal of this project is to learn how to use generative AI through prompt engineering and build a simple tool that generates professional cover letters based on user input.

I chose this project because AI-powered writing tools are widely used in real-world applications, and learning how to integrate AI APIs is a valuable skill.

---

## 2. Quick Summary of the Technology

**What is Gemini API?**  
Gemini API is a generative AI service by Google that allows developers to create applications capable of generating human-like text, answering questions, and assisting with content creation.

**Where is it used?**
- Chatbots
- Content generation tools
- Code assistants
- Writing automation tools

**Real-world example:**  
AI tools like ChatGPT or Google Gemini that generate emails, essays, and responses.
